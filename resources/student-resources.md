# Learning Resources — Python for Data Analytics

This page contains free resources that will help you throughout the course and beyond.

---

## 📚 Interactive Tutorials

These sites let you run Python code directly in the browser — no installation required.

### Kaggle Learn
- **Link:** https://www.kaggle.com/learn
- **What it is:** Short micro-courses on Python basics, pandas, data visualization, and data cleaning
- **Why:** Jupyter notebook environment right in the browser. Courses are short (3-4 hours each), hands-on, and come with a certificate. Work with real data from day one

### W3Schools Python
- **Link:** https://www.w3schools.com/python/
- **pandas section:** https://www.w3schools.com/python/pandas/default.asp
- **What it is:** Python fundamentals tutorial from variables to file handling
- **Why:** Every lesson has a "Try it Yourself" in-browser editor. No registration required. Includes quizzes and exercises

### LearnPython.org
- **Link:** https://www.learnpython.org/
- **What it is:** Python basics (variables, lists, loops, functions) + a data science section on pandas and numpy
- **Why:** Recommended by Python's official wiki for absolute beginners. Every lesson has a built-in code editor

### freeCodeCamp — Data Analysis with Python
- **Link:** https://www.freecodecamp.org/learn/data-analysis-with-python/
- **What it is:** Python basics, NumPy, pandas, data cleaning, visualization with Matplotlib and Seaborn. 5 certification projects
- **Why:** Completely free, including the certificate. Interactive from the very first lesson

## 📖 Official Documentation

These are the authoritative sources — check here when in doubt.

### Python Official Tutorial
- **Link:** https://docs.python.org/3/tutorial/
- **What it is:** The official Python tutorial: language fundamentals, data structures, modules, files, errors

### pandas — Getting Started
- **Tutorials:** https://pandas.pydata.org/docs/getting_started/intro_tutorials/
- **10 Minutes to pandas:** https://pandas.pydata.org/docs/user_guide/10min.html

### NumPy — Absolute Beginners Guide

## 💪 Practice Platforms

### Practice Python
- **Link:** https://www.practicepython.org/
- **What it is:** 40 beginner Python exercises — lists, strings, dictionaries, files
- **Why:** No registration required. Every exercise has a solution. Designed specifically for practice after a basic tutorial

### Exercism (Python Track)
- **Link:** https://exercism.org/tracks/python
- **What it is:** 146 Python exercises from beginner to advanced, with automated tests and mentoring
- **Why:** Completely free. The mentoring is unique — you can get human feedback on your code

### HackerRank (Python)
- **Link:** https://www.hackerrank.com/domains/python
- **What it is:** Python challenges sorted by topic: introduction, data types, strings, sets, math
- **Why:** Free. Problems are sorted by difficulty. You can earn certificates

### PYnative (Pandas Exercises)
- **Link:** https://pynative.com/python-pandas-exercise/
- **General Python:** https://pynative.com/python-exercises-with-solutions/
- **What it is:** pandas-specific exercises + 800+ general Python exercises
- **Why:** Specifically focused on data analytics skills

### w3resource (Pandas)
- **Link:** https://www.w3resource.com/python-exercises/pandas/index.php
- **What it is:** 3,490 pandas practice problems sorted by topic and difficulty
- **Why:** Massive problem bank. Great for lots of practice on a specific topic

### 101 Pandas Exercises
- **Link:** https://www.machinelearningplus.com/python/101-pandas-exercises-python/
- **What it is:** 101 pandas exercises at 3 difficulty levels
- **Why:** Includes solutions. Good for self-assessment after a pandas tutorial

### Codewars
- **Link:** https://www.codewars.com/
- **What it is:** Python "kata" (challenges) at all difficulty levels. Filter by 8-kyu/7-kyu for beginner problems
- **Why:** Free. Gamified with ranks. Seeing other people's solutions — a powerful way to learn

## 📋 Cheat Sheets

For quick reference — print them out and keep them on your desk.

### Dataquest Cheat Sheets
- **Link:** https://www.dataquest.io/cheat-sheet/
- **What it is:** Separate PDFs for Python basics, pandas, NumPy, Matplotlib
- **Why:** Well-designed, free, made specifically for data science students

### DataCamp Cheat Sheets
- **Link:** https://www.datacamp.com/cheat-sheet
- **What it is:** Individual cheat sheets for pandas, NumPy, Matplotlib, Seaborn, Jupyter
- **Why:** Visually clear, one-page format. The most widely shared data science cheat sheets

## 🗺️ Recommended Learning Path

For extra practice alongside the course:

1. **Python basics** → W3Schools Python Tutorial or Practice Python
2. **Learning pandas** → Kaggle Learn: Pandas micro-course
3. **Practicing pandas** → PYnative Pandas Exercises or 101 Pandas Exercises
4. **NumPy** → NumPy Absolute Beginners Guide
5. **Visualization** → Kaggle Learn: Data Visualization
6. **On your desk:** → Dataquest or DataCamp cheat sheets for pandas, NumPy, and Matplotlib
