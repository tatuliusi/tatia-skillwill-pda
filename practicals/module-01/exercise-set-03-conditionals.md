### ამოცანა 7: BMI კატეგორია

მოცემულია:
```python
weight = 75  # კგ
height = 1.75  # მ
```

გამოთვალეთ BMI (`weight / height ** 2`) და განსაზღვრეთ კატეგორია:
- BMI < 18.5: წონაში ნაკლები
- 18.5 <= BMI < 25: ნორმალური
- 25 <= BMI < 30: ჭარბი წონა
- BMI >= 30: სიმსუქნე

**მოსალოდნელი შედეგი:**
```
BMI: 24.49 — ნორმალური წონა
```

### ამოცანა 11: საშემოსავლო გადასახადი

მოცემულია წლიური შემოსავალი:
```python
income = 45000
```

გამოთვალეთ გადასახადი პროგრესული სისტემით:
- 0 – 15,000 ლარი: 0%
- 15,001 – 30,000 ლარი: 15%
- 30,001 – 50,000 ლარი: 20%
- 50,001+ ლარი: 25%

**მნიშვნელოვანი:** გადასახადი პროგრესულია — 45,000 ლარის შემთხვევაში:
- პირველ 15,000-ზე: 0%
- მომდევნო 15,000-ზე (15,001-30,000): 15%
- დანარჩენ 15,000-ზე (30,001-45,000): 20%

**მოსალოდნელი შედეგი:**
```
შემოსავალი: 45000 ლარი
გადასახადი: 5250.0 ლარი
ხელზე მისაღები: 39750.0 ლარი
```

### ამოცანა 12: მომხმარებლის input() ვალიდაცია

დაწერეთ პროგრამა, რომელიც:
1. ჰკითხავს მომხმარებელს ორ რიცხვს და ოპერატორს (+, -, *, /)
2. ასრულებს შესაბამის ოპერაციას
3. ყოფისას ამოწმებს ნულზე გაყოფას
4. არასწორი ოპერატორის შემთხვევაში აჩვენებს შეცდომას

**მაგალითი:**
```
პირველი რიცხვი: 10
მეორე რიცხვი: 3
ოპერატორი (+, -, *, /): /
შედეგი: 10.0 / 3.0 = 3.33
```

**ნულზე გაყოფის მაგალითი:**
```
პირველი რიცხვი: 10
მეორე რიცხვი: 0
ოპერატორი (+, -, *, /): /
შეცდომა: ნულზე გაყოფა შეუძლებელია!
```

    result = None

if result is not None:
    print(f"შედეგი: {num1} {operator} {num2} = {round(result, 2)}")
