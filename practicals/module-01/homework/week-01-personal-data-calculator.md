# საშინაო დავალება — კვირა 1: პერსონალური მონაცემთა კალკულატორი

## აღწერა

შექმენით Python სკრიპტი, რომელიც მომხმარებლისგან მონაცემებს მიიღებს, გამოთვლებს ჩაატარებს და შედეგებს ლამაზად დაფორმატებულ სახეში გამოიტანს. ეს დავალება აერთიანებს კვირის განმავლობაში შესწავლილ ყველა თემას: ცვლადები, ტიპები, ოპერატორები, სტრინგები, ფორმატირება და პირობითი კონსტრუქციები.

## ნაწილი 1: BMI კალკულატორი (სავალდებულო)

### დავალება
1. მომხმარებლისგან მოითხოვეთ **სახელი**, **წონა (კგ)** და **სიმაღლე (სმ)**
2. გამოთვალეთ **BMI** (Body Mass Index) ფორმულით: `BMI = წონა / (სიმაღლე_მეტრებში ** 2)`
3. BMI-ს მიხედვით განსაზღვრეთ **კატეგორია**:
   - BMI < 18.5 → "წონის დეფიციტი"
   - 18.5 ≤ BMI < 25 → "ნორმალური წონა"
   - 25 ≤ BMI < 30 → "ჭარბი წონა"
   - BMI ≥ 30 → "სიმსუქნე"
4. გამოიტანეთ ფორმატირებული შედეგი (იხილეთ მაგალითი ქვემოთ)

### მოსალოდნელი შედეგი
```
=== BMI კალკულატორი ===

შეიყვანეთ თქვენი სახელი: ნინო
შეიყვანეთ წონა (კგ): 65
შეიყვანეთ სიმაღლე (სმ): 170

--- შედეგები ---
სახელი: ნინო
წონა: 65.0 კგ
სიმაღლე: 1.70 მ
BMI: 22.49
კატეგორია: ნორმალური წონა
```

## ნაწილი 2: ასაკის კალკულატორი (სავალდებულო)

### დავალება
1. მომხმარებლისგან მოითხოვეთ **დაბადების წელი**
2. გამოთვალეთ:
   - **ასაკი** წლებში (მიმდინარე წელი: 2026)
   - **ასაკი დღეებში** (ასაკი × 365)
   - **ასაკი საათებში** (ასაკი_დღეებში × 24)
3. განსაზღვრეთ **თაობა**:
   - დაბადების წელი < 1965 → "Baby Boomer"
   - 1965 ≤ წელი < 1981 → "Generation X"
   - 1981 ≤ წელი < 1997 → "Millennial"
   - 1997 ≤ წელი < 2013 → "Generation Z"
   - წელი ≥ 2013 → "Generation Alpha"
4. გამოიტანეთ ფორმატირებული შედეგი

### მოსალოდნელი შედეგი
```
=== ასაკის კალკულატორი ===

შეიყვანეთ დაბადების წელი: 1998

--- შედეგები ---
ასაკი: 28 წელი
ასაკი დღეებში: 10220
ასაკი საათებში: 245280
თაობა: Generation Z
```

## ნაწილი 3: ტემპერატურის კონვერტორი (სავალდებულო)

### დავალება
1. მომხმარებლისგან მოითხოვეთ **ტემპერატურა** (რიცხვი) და **ერთეული** ("C" ან "F")
2. კონვერტაცია:
   - C → F: `F = C * 9/5 + 32`
   - F → C: `C = (F - 32) * 5/9`
3. განსაზღვრეთ **ამინდის აღწერა**:
   - < 0°C → "ყინვა"
   - 0–10°C → "ცივი"
   - 10–20°C → "გრილი"
   - 20–30°C → "თბილი"
   - > 30°C → "ცხელი"
4. თუ ერთეული არ არის "C" ან "F" — გამოიტანეთ შეცდომის შეტყობინება

### მოსალოდნელი შედეგი
```
=== ტემპერატურის კონვერტორი ===

შეიყვანეთ ტემპერატურა: 25
შეიყვანეთ ერთეული (C/F): C

--- შედეგები ---
25.0°C = 77.0°F
ამინდი: თბილი
```

## ბონუს ნაწილი: ვალუტის კონვერტორი (დამატებითი ქულებისთვის)

### დავალება
1. განსაზღვრეთ ცვლადები კურსებისთვის: `1 USD = 2.72 GEL`, `1 EUR = 2.95 GEL`, `1 GBP = 3.45 GEL`
2. მომხმარებლისგან მოითხოვეთ **თანხა** და **ვალუტა** (USD, EUR ან GBP)
3. გამოთვალეთ GEL ეკვივალენტი
4. თუ თანხა > 1000, გამოიტანეთ შეტყობინება: "დიდი ტრანზაქცია!"
5. ფორმატირება: 2 ათწილადი ნიშანი

### მოსალოდნელი შედეგი
```
=== ვალუტის კონვერტორი ===

შეიყვანეთ თანხა: 500
შეიყვანეთ ვალუტა (USD/EUR/GBP): EUR

--- შედეგები ---
500.00 EUR = 1475.00 GEL
```

## სასარგებლო მინიშნებები

- `input()` ყოველთვის სტრინგს აბრუნებს — არ დაგავიწყდეთ `int()` ან `float()` კონვერტაცია
- სიმაღლის სანტიმეტრებიდან მეტრებში გადასაყვანად: `height_m = height_cm / 100`
- BMI-ს 2 ათწილად ნიშნამდე დასამრგვალებლად: `f"{bmi:.2f}"`
- `upper()` მეთოდი სასარგებლოა ერთეულის შედარებისთვის: `unit.upper() == "C"`
- ტესტირებისთვის: BMI 22.49 = წონა 65კგ, სიმაღლე 170სმ
