### ამოცანა 11: ვალუტის გადამცვლელი

მოცემულია თანხა ლარებში: `450.75`. ამჟამინდელი კურსებია:

### ამოცანა 12: მანძილი ორ წერტილს შორის

მოცემულია ორი წერტილის კოორდინატები:
- წერტილი A: `x1 = 3`, `y1 = 4`
- წერტილი B: `x2 = 7`, `y2 = 1`

გამოთვალეთ მანძილი ფორმულით: `d = √((x2-x1)² + (y2-y1)²)`

გამოიყენეთ `**` ოპერატორი (კვადრატული ფესვისთვის `** 0.5`). დაამრგვალეთ 2 ათწილადამდე.

**მოსალოდნელი შედეგი:**
```
მანძილი: 5.0
```

### ამოცანა 13: რთული პროცენტი (Compound Interest)

საწყისი თანხაა `1000` ლარი, წლიური პროცენტი — `8%`, ვადა — `5` წელი.

გამოთვალეთ რთული პროცენტით დაგროვილი თანხა ფორმულით:
`A = P * (1 + r) ** t`

სადაც `P` = საწყისი თანხა, `r` = პროცენტი (ათწილადში), `t` = წლების რაოდენობა.

დაბეჭდეთ საბოლოო თანხა და მოგება (საბოლოო - საწყისი).

**მოსალოდნელი შედეგი:**
```
საბოლოო თანხა: 1469.33 ლარი
მოგება: 469.33 ლარი
```

---

### ამოცანა 14: დროის კალკულატორი

მოცემულია `100000` წამი. გადაიყვანეთ დღეებში, საათებში, წუთებსა და წამებში.

**მოსალოდნელი შედეგი:**
```
100000 წამი = 1 დღე, 3 საათი, 46 წუთი, 40 წამი
```

---

### ამოცანა 15: მაღაზიის ანგარიში

მაღაზიაში იყიდეთ:
- 3 წიგნი, თითო `12.99` ლარი
- 2 კალამი, თითო `1.50` ლარი
- 1 ჩანთა, `45.00` ლარი

გამოთვალეთ:
1. ჯამური ფასი დღგ-ს (18%) გარეშე (`subtotal`)
2. დღგ-ს თანხა (`vat`)
3. ჯამური ფასი დღგ-ით (`total`)
4. თუ იხდით `100` ლარს, რა ხურდა დაგრჩებათ? (`change`)

ყველა შედეგი დაამრგვალეთ 2 ათწილადამდე.

**მოსალოდნელი შედეგი:**
```
ქვეჯამი: 86.97 ლარი
დღგ (18%): 15.65 ლარი
სულ: 102.62 ლარი
ხურდა: -2.62 ლარი (არ გეყოფათ!)
```
