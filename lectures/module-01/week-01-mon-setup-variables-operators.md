## 2. ცვლადები და მონაცემთა ტიპები (25 წთ)

### საკვანძო საკითხები

- ცვლადი = სახელი, რომელიც მიუთითებს მნიშვნელობაზე მეხსიერებაში
- მინიჭება `=` ოპერატორით (ეს არ არის ტოლობა მათემატიკური გაგებით)
- სახელდების წესები: იწყება ასოთი ან `_`, არ შეიძლება ციფრით; `snake_case` კონვენცია
- ძირითადი ტიპები: `int`, `float`, `str`, `bool`, `None`
- `type()` ფუნქცია — ტიპის შემოწმება
- დინამიური ტიპიზაცია: ცვლადს ტიპი არ აქვს, მნიშვნელობას აქვს

### კოდის მაგალითები

**ცვლადების შექმნა და ტიპები:**
```python
age = 25                    # int — მთელი რიცხვი
salary = 3500.50            # float — წილადი რიცხვი
name = "თათია"              # str — ტექსტი (სტრინგი)
is_student = True           # bool — ლოგიკური (True/False)
middle_name = None          # None — "არაფერი", მნიშვნელობა არ არსებობს
```

**ტიპის შემოწმება:**
```python
print(type(age))            # <class 'int'>
print(type(salary))         # <class 'float'>
print(type(name))           # <class 'str'>
print(type(is_student))     # <class 'bool'>
print(type(middle_name))    # <class 'NoneType'>
```

**გადანიშვნა და დინამიური ტიპიზაცია:**
```python
x = 10
print(type(x))    # <class 'int'>

x = "hello"
print(type(x))    # <class 'str'> — იგივე ცვლადი, ახალი ტიპი!
```

**მრავალი ცვლადის მინიჭება:**
```python
a, b, c = 1, 2, 3
x = y = z = 0
```

**ცვლადის წაშლა:**
```python
temp = 100
del temp
# print(temp)  # NameError: name 'temp' is not defined
```

**სახელდების კარგი და ცუდი მაგალითები:**
```python
# კარგი სახელები
student_count = 30
monthly_salary = 2500.0
is_active = True

# ცუდი სახელები (მუშაობს, მაგრამ წაუკითხავია)
x = 30
ms = 2500.0
flag = True

# არასწორი სახელები (შეცდომას იძლევა)
# 2nd_name = "ლუკა"      # ციფრით იწყება
# my-name = "ანა"         # ტირე არ შეიძლება
# class = "A"             # დარეზერვებული სიტყვა
```

### გავრცელებული შეცდომები

- `=` და `==` აურიება — `=` არის მინიჭება, `==` არის შედარება
- `True`/`False` პატარა ასოთი წერა → `true` არ არსებობს Python-ში
- ცვლადის სახელში ქართული ასოების გამოყენება → ტექნიკურად მუშაობს, მაგრამ არ არის რეკომენდებული
- `None` და `"None"` აურიება — ერთი არის სპეციალური ტიპი, მეორე ტექსტია

### კავშირი მონაცემთა ანალიტიკასთან

- ნებისმიერი dataset შედგება ამ ტიპებისგან: რიცხვები (int/float), ტექსტი (str), ლოგიკური (bool)
- `None` არის pandas-ის `NaN`-ის წინამორბედი — "გამოტოვებული მნიშვნელობა"
- ცვლადების სწორი სახელდება კრიტიკულია — თქვენი კოდი სხვამაც უნდა წაიკითხოს

> **გადასვლა:** ვიცით რა ტიპის მონაცემები არსებობს — ახლა ვნახოთ რა ოპერაციები შეგვიძლია მათზე.

## 3. ოპერატორები (25 წთ)

### საკვანძო საკითხები

- არითმეტიკული ოპერატორები: `+`, `-`, `*`, `/`, `//`, `%`, `**`
- შედარების ოპერატორები: `==`, `!=`, `>`, `<`, `>=`, `<=`
- ლოგიკური ოპერატორები: `and`, `or`, `not`
- ოპერატორების პრიორიტეტი (precedence)
- შედეგის ტიპი: `int / int = float`, `int // int = int`

### კოდის მაგალითები

**არითმეტიკული ოპერატორები:**
```python
a = 17
b = 5

print(a + b)     # 22   — შეკრება
print(a - b)     # 12   — გამოკლება
print(a * b)     # 85   — გამრავლება
print(a / b)     # 3.4  — გაყოფა (ყოველთვის float!)
print(a // b)    # 3    — მთელრიცხვა გაყოფა
print(a % b)     # 2    — ნაშთი
print(a ** b)    # 1419857  — ხარისხში აყვანა (17^5)
```

**float-ის თავისებურებები:**
```python
print(10 / 3)       # 3.3333333333333335
print(0.1 + 0.2)    # 0.30000000000000004 (!)
print(10 / 5)       # 2.0 (არა 2, გაყოფა ყოველთვის float-ს აბრუნებს)
```

**შედარების ოპერატორები:**
```python
x = 10
y = 20

print(x == y)    # False — ტოლია?
print(x != y)    # True  — არ არის ტოლი?
print(x > y)     # False — მეტია?
print(x < y)     # True  — ნაკლებია?
print(x >= 10)   # True  — მეტია ან ტოლი?
print(x <= 5)    # False — ნაკლებია ან ტოლი?
```

**ლოგიკური ოპერატორები:**
```python
age = 25
salary = 3000

print(age > 18 and salary > 2000)   # True  — ორივე პირობა ჭეშმარიტი
print(age > 30 or salary > 2000)    # True  — ერთი მაინც ჭეშმარიტი
print(not age > 30)                 # True  — პირობის უარყოფა
```

**ოპერატორების პრიორიტეტი (მაღალიდან დაბალისკენ):**
```python
# ** → (*, /, //, %) → (+, -) → (==, !=, <, >, <=, >=) → not → and → or

result = 2 + 3 * 4        # 14 (არა 20!)
result = (2 + 3) * 4      # 20 (ფრჩხილები ცვლის თანმიმდევრობას)
result = 2 ** 3 ** 2       # 512 (** მარჯვნიდან: 2^(3^2) = 2^9)
result = True or False and False  # True (and პირველი: True or False = True)
```

**პრაქტიკული მაგალითი — ხელფასის გამოთვლა:**
```python
hourly_rate = 15
hours_worked = 160
tax_rate = 0.20

gross_salary = hourly_rate * hours_worked
tax_amount = gross_salary * tax_rate
net_salary = gross_salary - tax_amount

print(gross_salary)   # 2400
print(tax_amount)     # 480.0
print(net_salary)     # 1920.0
```

### გავრცელებული შეცდომები

- `/` და `//` აურიება → `/` ყოველთვის float-ს აბრუნებს, `//` კი მთელ რიცხვს
- `0.1 + 0.2 != 0.3` → floating-point არითმეტიკის თავისებურება, არა Python-ის ბაგი
- ოპერატორების პრიორიტეტის დავიწყება → ეჭვის შემთხვევაში გამოიყენეთ ფრჩხილები
- `=` მინიჭების ნაცვლად `==` შედარებაში (და პირიქით)

### კავშირი მონაცემთა ანალიტიკასთან

- `%` (ნაშთი) სასარგებლოა მონაცემების ჯგუფებად დასაყოფად (მაგ: ლუწი/კენტი)
- შედარების ოპერატორები საფუძველია მონაცემთა ფილტრაციისთვის pandas-ში: `df[df["age"] > 25]`
- ხელფასის, გადასახადის, პროცენტის გამოთვლები — ტიპიური ანალიტიკური ამოცანები

> **გადასვლა:** ვიცით ცვლადები, ტიპები და ოპერატორები — ახლა ერთ პროგრამაში გავაერთიანოთ.

## 4. ცოცხალი კოდირება — ყველაფრის ერთად (20 წთ)

### დემო: სტუდენტის პროფილის ანალიზი

ეტაპობრივად ააწყვეთ ეკრანზე, სტუდენტებს აჩვენეთ პროცესი:

```python
# === სტუდენტის მონაცემები ===
student_name = "ლუკა"
age = 22
gpa = 3.45
is_enrolled = True
scholarship = None

# === ტიპების შემოწმება ===
print(type(student_name))   # <class 'str'>
print(type(age))            # <class 'int'>
print(type(gpa))            # <class 'float'>
print(type(is_enrolled))    # <class 'bool'>
print(type(scholarship))    # <class 'NoneType'>

# === გამოთვლები ===
credits_completed = 120
credits_required = 240
progress_percent = credits_completed / credits_required * 100

print(progress_percent)     # 50.0

# === შედარებები ===
print(gpa > 3.0)            # True
print(age >= 21)            # True
print(scholarship != None)  # False

# === ლოგიკური კომბინაციები ===
eligible_for_honors = gpa > 3.5 and credits_completed > 100
print(eligible_for_honors)  # False (gpa 3.45 < 3.5)

eligible_for_award = gpa > 3.3 or credits_completed > 200
print(eligible_for_award)   # True (gpa 3.45 > 3.3)
```

### ბონუს დემო: ტემპერატურის კონვერტაცია

```python
celsius = 36.6
fahrenheit = celsius * 9 / 5 + 32
kelvin = celsius + 273.15

print(fahrenheit)   # 97.88
print(kelvin)       # 309.75

is_fever = celsius > 37.0
print(is_fever)     # False
```
