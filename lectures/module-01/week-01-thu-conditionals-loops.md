## 1. პირობითი ოპერატორების გამეორება (10 წთ)

### საკვანძო საკითხები — ხშირი შეცდომები გუშინდელი მასალიდან

- `=` vs `==` — მინიჭება vs შედარება
- ინდენტაციის თანმიმდევრულობა — ერთ ბლოკში ერთნაირი
- `elif`-ების თანმიმდევრობა — პირველი ჭეშმარიტი შესრულდება
- `and`/`or` პრიორიტეტი — `and` პირველია

### კოდის მაგალითები

**შეცდომა #1 — `=` ნაცვლად `==`:**
```python
x = 10

# შეცდომა:
# if x = 10:        # SyntaxError!

# სწორი:
if x == 10:
    print("x არის 10")
```

**შეცდომა #2 — elif-ების თანმიმდევრობა:**
```python
score = 95

# არასწორი თანმიმდევრობა:
if score >= 60:
    print("D")       # ეს შესრულდება! 95 >= 60
elif score >= 90:
    print("A")       # ამას ვერასდროს მივაღწევთ

# სწორი — მაღალიდან დაბალისკენ:
if score >= 90:
    print("A")       # 95 >= 90 → True
elif score >= 60:
    print("D")
```

**შეცდომა #3 — ზედმეტი elif ნაცვლად if:**
```python
temp = 35
humidity = 80

# თუ ორი დამოუკიდებელი შემოწმებაა — ცალკე if-ები:
if temp > 30:
    print("ცხელა")
if humidity > 70:
    print("ტენიანობა მაღალია")

# elif გამოიყენეთ მხოლოდ ერთი შემთხვევის არჩევისთვის:
if temp > 30:
    print("ცხელა")
elif temp > 20:
    print("თბილა")
else:
    print("ცივა")
```

> **გადასვლა:** პირობებს კარგად ვიცნობთ — ახლა ვისწავლოთ კოდის მრავალჯერ გაშვება ციკლის საშუალებით.

## 2. while ციკლი (20 წთ)

### საკვანძო საკითხები

- `while` ციკლი: კოდის ბლოკს ასრულებს სანამ პირობა ჭეშმარიტია
- სტრუქტურა: `while condition:` → ბლოკი (ინდენტაციით)
- მთვლელის პატერნი (counter pattern): ცვლადი იზრდება ყოველ იტერაციაზე
- აკუმულატორის პატერნი: ჯამის, საშუალოს გამოთვლა ციკლით
- უსასრულო ციკლის საფრთხე — ყოველთვის დარწმუნდით რომ პირობა შეიცვლება!

### კოდის მაგალითები

**მარტივი while:**
```python
count = 1

while count <= 5:
    print(f"იტერაცია {count}")
    count += 1      # count = count + 1

print("ციკლი დასრულდა!")
```

**გამოტანა:**
```
იტერაცია 1
იტერაცია 2
იტერაცია 3
იტერაცია 4
იტერაცია 5
ციკლი დასრულდა!
```

**მთვლელის პატერნი — ცხრილის ბეჭდვა:**
```python
print("გამრავლების ცხრილი (7):")
i = 1
while i <= 10:
    result = 7 * i
    print(f"7 x {i} = {result}")
    i += 1
```

**აკუმულატორის პატერნი — ჯამის გამოთვლა:**
```python
total = 0
count = 1

while count <= 100:
    total += count      # total = total + count
    count += 1

print(f"1-დან 100-მდე ჯამი: {total}")   # 5050
```

**while + input() — მომხმარებლის შეყვანა ციკლში:**
```python
total = 0
item_count = 0

price = float(input("შეიყვანეთ ფასი (0 დასასრულებლად): "))

while price != 0:
    total += price
    item_count += 1
    price = float(input("შეიყვანეთ ფასი (0 დასასრულებლად): "))

print(f"\nპროდუქტების რაოდენობა: {item_count}")
print(f"ჯამური თანხა: {total:.2f} ₾")
if item_count > 0:
    print(f"საშუალო ფასი: {total / item_count:.2f} ₾")
```

**while + ვალიდაცია — სწორი შეყვანის მოთხოვნა:**
```python
age = int(input("შეიყვანეთ ასაკი (1-120): "))

while age < 1 or age > 120:
    print("შეცდომა! ასაკი უნდა იყოს 1-დან 120-მდე.")
    age = int(input("სცადეთ თავიდან: "))

print(f"თქვენი ასაკი: {age}")
```

### გავრცელებული შეცდომები

- **უსასრულო ციკლი** — პირობა არასდროს ხდება False:
```python
# საშიში! ნუ გაუშვებთ!
# count = 1
# while count <= 5:
#     print(count)
#     # count += 1 დავიწყდა! → ყოველთვის 1-ს ბეჭდავს
```
- მთვლელის განახლების დავიწყება → ციკლი არასდროს მთავრდება
- `+=` ნაცვლად `=` → `count = count + 1` ნაცვლად `count + 1` (ეს ბოლო არაფერს არ ცვლის)
- off-by-one შეცდომა: `<` vs `<=` — ერთით მეტი ან ნაკლები იტერაცია

### კავშირი მონაცემთა ანალიტიკასთან

- ციკლი = მონაცემების თითოეული ჩანაწერის დამუშავება
- აკუმულატორი = ჯამი, საშუალო, მინიმუმი, მაქსიმუმი — ანალიტიკის ფუნდამენტი
- ვალიდაციის ციკლი = მონაცემთა ხარისხის კონტროლი
- pandas-ის `.apply()`, `.iterrows()` ციკლებს ამარტივებს, მაგრამ ლოგიკა იგივეა

> **გადასვლა:** ციკლი მუშაობს, მაგრამ ხანდახან გვჭირდება მისი ნაადრევად შეწყვეტა ან იტერაციის გამოტოვება.

## 3. break და continue (10 წთ)

### საკვანძო საკითხები

- `break` — ციკლის სრულად შეწყვეტა (გამოდის ციკლიდან)
- `continue` — მიმდინარე იტერაციის გამოტოვება (გადადის შემდეგზე)
- `while True` + `break` — ძალიან გავრცელებული პატერნი

### კოდის მაგალითები

**break — ძიება ციკლში:**
```python
target = 7
current = 1

while current <= 100:
    if current == target:
        print(f"ნაპოვნია: {target}")
        break
    current += 1
```

**continue — კენტი რიცხვების გამოტოვება:**
```python
i = 0
while i < 10:
    i += 1
    if i % 2 != 0:
        continue
    print(f"{i} — ლუწი რიცხვი")
# 2, 4, 6, 8, 10
```

**while True + break — ინტერაქტიული მენიუ:**
```python
while True:
    command = input("\nშეიყვანეთ ბრძანება (help/quit): ").lower().strip()

    if command == "quit":
        print("ნახვამდის!")
        break
    elif command == "help":
        print("ხელმისაწვდომი ბრძანებები: help, quit")
    else:
        print(f"უცნობი ბრძანება: {command}")
```

**break + else ბლოკი (while...else):**
```python
password = "python123"
attempts = 0

while attempts < 3:
    guess = input("პაროლი: ")
    if guess == password:
        print("წარმატებული შესვლა!")
        break
    attempts += 1
    print(f"არასწორი! დარჩა {3 - attempts} მცდელობა")
else:
    print("ანგარიში დაბლოკილია!")
```

### გავრცელებული შეცდომები

- `break` და `continue` ციკლის გარეთ → `SyntaxError`
- `while True` ციკლში `break`-ის დავიწყება → უსასრულო ციკლი
- `continue`-ს შემდეგ მთვლელის განახლება → ციკლი არასდროს მთავრდება:
```python
# საშიში!
# i = 0
# while i < 5:
#     if i == 3:
#         continue    # i არასდროს გაიზრდება!
#     print(i)
#     i += 1
```

### კავშირი მონაცემთა ანალიტიკასთან

- `break` — პირველი შედეგის პოვნისას ძიების შეწყვეტა (ეფექტურობა)
- `continue` — არასწორი/ცარიელი მონაცემების გამოტოვება
- `while True` + `break` — ინტერაქტიული ანალიტიკური სკრიპტები

## 4. ცოცხალი კოდირება (20 წთ)

### დემო 1: რიცხვების გამოცნობის თამაში

```python
import random

secret = random.randint(1, 50)
attempts = 0
max_attempts = 7

print("=== რიცხვის გამოცნობა ===")
print(f"გამოიცანით რიცხვი 1-დან 50-მდე ({max_attempts} მცდელობა)\n")

while attempts < max_attempts:
    guess = int(input("თქვენი ვარიანტი: "))
    attempts += 1

    if guess == secret:
        print(f"\n🎉 გამოიცანით! რიცხვი იყო {secret}")
        print(f"მცდელობების რაოდენობა: {attempts}")
        break
    elif guess < secret:
        print("მეტია! ↑")
    else:
        print("ნაკლებია! ↓")

    remaining = max_attempts - attempts
    if remaining > 0:
        print(f"დარჩა {remaining} მცდელობა\n")
else:
    print(f"\nწააგეთ! რიცხვი იყო {secret}")
```

### დემო 2: მინი ხარჯების ტრეკერი

```python
print("=== ხარჯების ტრეკერი ===")
print("შეიყვანეთ ხარჯები. ჩაწერეთ 'done' დასასრულებლად.\n")

total = 0
count = 0
max_expense = 0
min_expense = float('inf')

while True:
    entry = input("ხარჯი (₾): ").strip()

    if entry.lower() == "done":
        break

    amount = float(entry)

    if amount <= 0:
        print("თანხა დადებითი უნდა იყოს! გამოტოვებულია.")
        continue

    total += amount
    count += 1

    if amount > max_expense:
        max_expense = amount
    if amount < min_expense:
        min_expense = amount

    print(f"  ჯამი ჯერჯერობით: {total:.2f} ₾")

# შედეგები
print("\n" + "=" * 30)
if count > 0:
    average = total / count
    print(f"ხარჯების რაოდენობა: {count}")
    print(f"ჯამური ხარჯი:      {total:.2f} ₾")
    print(f"საშუალო ხარჯი:     {average:.2f} ₾")
    print(f"ყველაზე დიდი:      {max_expense:.2f} ₾")
    print(f"ყველაზე პატარა:    {min_expense:.2f} ₾")

    if total > 500:
        print("\n⚠️ ყურადღება: ხარჯები 500₾-ს აღემატება!")
else:
    print("ხარჯები არ შეიყვანეთ.")
```
