# Python for Data Analytics - Skillwill

> Course materials, lesson plans, and teaching resources for the Python for Data Analytics program at [Skillwill](https://skillwill.ge/).

## Overview

This repository serves as a structured knowledge base for delivering a Python for Data Analytics course. It contains everything from syllabus design and lecture notes to in-class exercises and classroom management plans — organized by session for easy navigation.

## Repository Structure

```
├── syllabus/              # Course overview, schedule, and learning objectives
├── lectures/              # Slide decks and lecture notes (per session)
├── practicals/            # In-class exercises, datasets, and solutions (per session)
├── behavioral-plans/      # Pacing, engagement, and classroom management plans (per session)
└── resources/             # Shared references, cheat sheets, templates, and reading lists
```

### Session Naming Convention

All session-based directories follow a consistent naming pattern:

```
session-01-intro-to-python/
session-02-data-structures/
session-03-pandas-basics/
...
```

This makes it straightforward to locate and cross-reference materials for any given class.

## Tech Stack

- **Language:** Python 3
- **Core Libraries:** pandas, NumPy, matplotlib (and others as the course progresses)
- **IDE:** PyCharm / VS Code

🟢 **Active** - Course is in progress. Materials are added and refined as sessions are planned and delivered.
